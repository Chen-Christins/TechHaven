# TechHaven v1.1.0 发布：私信上线，多设备可管，Agent UI 可选接入

> v1.1.0 在架构层面做了三件事：把 Agent UI 做成可选开关、把前端与 Agent 服务彻底解耦、把 CI 的构建拓扑补完整；功能层面则带来了期待已久的私信系统和多设备登录管理。

v1.0.1 打磨了主题的手感，v1.1.0 开始补社交和协作的拼图。这一版最大的变化不是某个具体功能，而是架构上的「可插拔」——Agent UI 不再是硬编码的一部分，而是一个可以随时开关的可选模块，关闭时零开销，开启时独立接入。在此基础上，私信和多设备管理两个实用功能也正式上线了。

## 架构：可选 Agent UI 与前后端解耦

### Agent UI 开关化

v1.1.0 引入了 `VITE_AGENT_ENABLED` 环境变量控制 Agent UI 的构建与运行。默认关闭，生产构建不会输出任何 Agent 相关的路由、导航入口和资源包；开发时设置为 `true` 即可启用 `/rd/agent` 入口，支持本地演示和网关代理两种驱动模式。

这意味着：

- **关闭时零开销**：主构建不包含 Agent 页面代码，bundle 体积不受影响。
- **开启时独立接入**：通过 Vite 代理连接本地 Gateway（默认 `http://127.0.0.1:3091`），或通过 `/rd/agent?driver=gateway` 连接远程服务。
- **故障边界清晰**：网关不可用时返回 503 并显示重试提示，不会自动回退到演示模式。

### 前端与 Agent 服务解耦

Agent 服务（Gateway、BFF、Bridge、MCP）已迁移到独立仓库 `TechHaven-agent-services`，与前端仓库完全解耦。前端不再引用同级仓库源码，不保存管理令牌，安装、检查、发布均独立进行。

共享部分（文章渲染、个人页面、研发列表、管理页样式）通过公共模块复用，两侧各自维护自己的业务逻辑。

### CI 构建拓扑扩展

CI 流水线新增了三项检查：

1. **Agent 合同检查**（`check:agent-contract`）：比对 `src/contracts/agent/index.d.ts` 与远端契约的类型一致性。
2. **边界检查**（`check-agent-boundary.mjs`）：验证 Agent 页面代码不会侵入主构建。
3. **Bundle 体积预算**（`check-bundle-size.mjs`）：确保新增功能不会导致包体积失控。

同时，CI 的 push/PR 触发分支限制为 master，部署工作流统一使用 Node 24，避免版本漂移。

## 功能：私信系统

v1.1.0 带来了完整的私信功能，入口在「个人中心 → 消息」。

### 会话列表

左侧展示所有会话，按最近消息时间倒序排列。每个会话显示对方头像、昵称、最后一条消息预览和时间戳，未读消息以红点标识。支持搜索互关用户发起新会话——只有互相关注的用户才能私信，避免骚扰。

### 实时消息

消息收发基于 WebSocket（`chatWS` 单例），支持实时推送。消息气泡区分自己（右侧蓝色）和对方（左侧灰色），每条消息带时间戳。滚动到顶部自动加载更多历史消息。

### 会话管理

支持删除会话（仅本端隐藏，对端和消息不受影响），带确认弹窗防误操作。消息自动标记已读，未读计数实时更新。

### 权限控制

普通用户（role 为"用户"或数字 1）无法使用私信功能，页面会显示权限不足提示。这为后续的角色分级预留了空间。

## 功能：多设备登录管理

账户安全页新增「登录设备」模块，展示当前账号的所有登录设备信息。

### 设备列表

每条设备记录包含设备名称、平台（桌面/移动端）、IP 地址、登录时间和最后活跃时间。当前设备会有醒目标识，方便区分。

### 单设备下线

点击任意设备的「下线」按钮，确认后立即使该设备的会话失效。适用于账号被盗、设备丢失等场景——不需要改密码，直接踢掉可疑设备即可。

### 移动端适配

设备列表在移动端做了响应式布局，操作按钮和设备信息都能正常展示。

## 写在最后

v1.1.0 是一次「内外兼修」的更新：对外补上了私信和设备管理两个实用功能，对内把 Agent UI 做成了可选模块，为后续的渐进式集成打下了基础。

接下来的版本会继续完善私信的富媒体能力（图片、文件），并把多设备管理与通知系统打通。如果你也在关注 Agent 能力的集成，现在可以通过开关逐步体验，而不必等到它完全成熟。
