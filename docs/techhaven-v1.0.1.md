# TechHaven v1.0.1 发布：主题有了「指尖感」与「纸格终端」

> 在 v1.0.0 把「写作 + 研发」放进同一个空间之后，v1.0.1 开始打磨这间空间的「手感」。

v1.0.0 让 TechHaven 有了时代周刊、樱花粉、赛博朋克等一系列主题风格。v1.0.1 沿着这条线继续往下走：不只是「换个配色」，而是让主题真正浸入每一个交互细节——鼠标指针跟着主题换、背景有了粒子与点击反馈、文章目录定位更聪明、返回顶部也终于「指哪打哪」。

这篇文章聊聊 v1.0.1 带来了什么。

## 新增「Pi 极客」主题：纸与格，终端的心

主题风格面板里多了一位新成员：**Pi 极客**。

它走的是「纸格终端」路线——暖米色的纸面底色（`#ebe7e4`）、墨蓝灰的主色（`#4b607c`）、偏暗的刊头色（`#252f3d`），标题用衬线字体，整体像一张铺开的工程图纸，又带着终端屏幕的克制感。暗色模式下则切到深空蓝灰，白天夜里各有各的安静。

## 主题背景：会呼吸的纸面

每个主题的背景不再是纯色，而是有了属于自己的「背景语言」：

- **Pi 极客**：双层工程纸网格（细格 5px + 粗格 25px）缓慢滚动，配上带十字定位标线的粒子，像是示波器上的定位光标。
- **樱花**：粉色花瓣缓缓上浮飘落。
- **薰衣草**：细长花瓣在风中摇曳。
- **暗金奢华**：细碎金屑缓缓沉降。

更妙的是**点击反馈**——在页面上任意点击，会以落点为圆心绽开一组与该主题配色一致的小粒子，片刻后消散。全部动画都适配了系统的「减少动态效果」偏好（`prefers-reduced-motion`），对晕动敏感的用户会自动关闭，不打扰、不强制。

## 各主题专属鼠标指针

鼠标指针也随主题而变了。`public/cursors/` 下为每个主题准备了一套手绘 SVG 指针：时代周刊是圆珠笔头、赛博朋克是霓虹十字、Pi 极客是一枚米字准星……点开主题风格面板底部的「主题鼠标」开关即可启用（默认开启），会跟随当前主题自动切换；不需要时一键关回系统默认。

## 文章目录（TOC）重构：更准、更稳

目录是长文阅读的核心，这一版对它做了一次较深的重构：

- **不再误伤代码块**：此前目录解析用的是正则匹配 `#` 开头行，会错误地把代码块里的 `# 注释` 当成标题。现在改为按行解析、用围栏状态机跳过 fenced code block，代码里的标题不再混入目录。
- **激活项更贴合真实滚动**：弃用 IntersectionObserver，改为基于实际滚动容器的位置计算——文章位于 SimpleBar 容器内，用它来计算激活线，页面顶部默认选中第一个标题、滚到底部固定选中最后一个，平滑滚动过程中目录状态也保持正确。
- **定位精确**：点目录跳转时减去导航栏高度（76px），标题不再被吸到页面边缘；到达目标后 URL 哈希同步更新。

## 返回顶部：终于「指哪打哪」

返回顶部按钮此前为了兼容多种滚动容器，用了一连串「方法 1 到方法 4」的兜底暴力滚动。v1.0.1 改成了优雅的做法：先检测当前是否处于 SimpleBar 滚动容器，是则在容器内平滑滚动，否则回退到 `window`——并且通过事件与文章目录联动，回到顶部后目录自动高亮第一个标题，不再出现「按钮点了、目录还停在半路」的错位。

## 写在最后

v1.0.1 没有大刀阔斧的新模块，它把功夫下在了「手感」上：主题从外表的配色延伸到指针、背景、点击反馈；阅读从目录解析、滚动定位到返回顶部，每个环节都更稳更顺。好看与好用，这一版都在往前。

接下来的版本，我们会继续补主题细节，并逐步把订阅、更多协作能力推进。欢迎来 TechHaven，换一套主题，点一点页面，感受一下这版的手感。
