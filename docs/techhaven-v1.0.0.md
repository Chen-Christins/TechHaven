# TechHaven v1.0.0 发布：当博客遇上研发协作

> 写作 + 研发一体化的技术团队工作空间，首个正式版本来了。

很长一段时间里，「写文章」和「做研发」是两件事：文章在博客系统里，需求、缺陷、评审在另一套研发工具里。TechHaven 想把它们放进同一个空间——你既能在里面安静地写作、发布、与读者互动，也能在同一个平台里跑需求、修缺陷、做代码评审、跟趋势。

今天，TechHaven 迎来首个正式版本 **v1.0.0**，对应目前 `master` 分支节点。这篇文章简单聊聊它是什么，以及这一版带来了什么。

## TechHaven 是什么

TechHaven 是一个面向技术团队的「研发 × 博客」一体化平台前端。它不只是博客：

- **博客内容**：首页信息流、文章发布/编辑、Markdown 渲染（代码高亮、KaTeX 公式、Mermaid 图表）、AI 摘要（SSE 流式）。
- **社区互动**：评论树、点赞、关注、订阅、在线人数与在线状态。
- **组织协作**：组织列表/详情、组织申请、作业发布与提交。
- **研发平台**：研发看板、需求/缺陷/任务管理、代码评审、工单与趋势分析。
- **管理后台**：用户、文章、作业、组织、评论、分类、媒体、数据、通知、系统设置。

技术上它基于 React 19 + TypeScript + Vite，样式采用 CSS Modules + CSS 自定义属性驱动明暗主题与页面宽度，网络层封装了带中文业务状态码映射的 axios 实例，认证 Token 存于内存（避免 localStorage 篡改）。

## v1.0.0 有哪些变化

### 新增：侧边栏「每日一言」

首页右侧栏新增了一个轻量组件，调用公开的一言（Hitokoto）接口，每天展示一句来自动漫、诗词、游戏或文学的话。它按日期缓存，避免重复请求；如果你看腻了，点一下刷新按钮就能换一条。

### 变更：默认主题改为「时代周刊」

此前默认是通用扁平风，现在默认就是「时代周刊」纸刊衬线风——暖色纸张底、红色刊头、衬线标题，更有「读杂志」的味道。主题风格面板里原有的「默认」选项已移除，你可以继续在极简黑白、护眼豆绿、海洋蓝、樱花粉、赛博朋克、暗金奢华、薰衣草紫之间切换。

### 变更：CI/CD 改为基于 Tag 的发布

这是底层最重要的一次调整：

- **master 推送与 PR**：只做构建检查，不再自动部署，避免未经验证的代码直接上线。
- **`v*` 标签推送**（如 `v1.0.0`）：才触发构建、部署与发版。部署目录从时间戳改为标签名，与 GitHub Release 一一对应，回滚时只需把软链接指回旧目录。
- **发布说明自动生成**：部署流水线会读取 `CHANGELOG.md` 中对应版本的段落，作为 GitHub Release 的说明。

### 其他

- 首页「订阅更新」卡片改为仅开发环境可见（订阅功能尚未实现，先不对外暴露）。

## 代码审查：直连 GitHub 仓库的 PR

研发平台里的「代码审查」不是又一个孤立的评审台，而是直接对接你关联的 GitHub 仓库。进入代码审查页后，选择对应仓库即可**查看该 GitHub 仓库下的所有 Pull Request**——无论是进行中、已合并还是已关闭的 PR，都会同步进来。

每一条 PR 都带有完整的上下文：PR 编号与标题、来自 GitHub 的状态（open / closed / merged）、关联的审查人、改动统计（增删行数、文件数），以及一键跳转回 GitHub 原 PR 的链接。平台还会定时轮询同步状态，确保你看到的就是仓库里最新的审查进展。

换句话说，团队在 GitHub 上提出的每一次变更，都能在 TechHaven 的研发空间里被追踪、讨论和复盘，而不必在博客系统和代码托管平台之间反复横跳。


## 我们是怎么发版的

如果你也在维护一个前端项目，下面是 TechHaven 现在的发版节奏，很简单：

1. 在 `CHANGELOG.md` 里新增一个版本段落，例如 `## [v1.1.0] - 2026-09-01`，写下这一版做了什么。
2. 打标签并推送：

```bash
git tag v1.1.0
git push origin v1.1.0
```

3. 剩下的交给流水线：自动构建 → 部署到 `releases/v1.1.0` → 切换软链接 → 根据 `CHANGELOG.md` 生成 GitHub Release。

整个过程不需要手动登录服务器，也不需要手写一篇发布说明。

## 写在最后

v1.0.0 是一个起点，不是终点。接下来我们会把订阅、更多主题细节、以及研发平台更深入的协作能力逐步补齐。如果你也想在一个「能写、能协作、能发布」的地方工作，欢迎关注 TechHaven。
