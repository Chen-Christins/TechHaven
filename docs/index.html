核心功能

📝

博客内容

首页信息流、文章发布/编辑、Markdown 渲染（代码高亮、KaTeX 公式、Mermaid 图表）、AI 流式摘要。

💬

社区互动

评论树、点赞、关注、订阅、在线状态 — 构建活跃的技术社区。

🤝

组织协作

组织列表与详情、组织申请、作业发布与提交，支持团队化协作。

🔧

研发平台

研发看板、需求/缺陷/任务管理、代码评审、工单系统、趋势分析。

⚙️

管理后台

用户、文章、作业、组织、评论、分类、媒体、数据、通知、系统设置。

🔐

系统能力

内存态 Token 认证、WebSocket 实时通知、维护模式守卫、明暗主题、页面宽度切换、分片上传。
